JOBAGENT · PRIVACY

Privacy Policy

JobAgent helps people reuse information they have chosen to save when completing recruitment application forms. The extension works only after the user starts it and stops before final submission so the user can review every answer.

1. Scope and purpose

This policy explains how the JobAgent browser extension and its companion service collect, use, store, and share information. JobAgent has one purpose: to use job-search information supplied by the user to identify and fill fields on the recruitment page the user has opened, while leaving uncertain answers and the final submission to the user.

2. Information we handle

  • Personally identifiable information: resume files and information the user uploads or enters, such as name, email address, phone number, city, education, employment, projects, research, skills, and custom job-application fields.
  • Authentication information: the invitation code used to access an account and the session token used to keep the extension signed in. The server stores only a hash of the session token.
  • Location-related network information: the IP address needed for login rate limiting, abuse prevention, and basic service security. JobAgent does not request GPS or precise device location.
  • Web history for the active task: the URL and title of the recruitment page on which the user starts JobAgent. JobAgent does not collect an unrelated list of pages visited.
  • Website content: form labels, field types, available options, nearby instructions, section headings, and existing field state needed to understand and complete the active application form.
  • Field memory: non-sensitive custom answers the user chooses to reuse and structural information that helps recognize similar fields on later applications.
  • Operational information: request time, request path, response status, network address, and other limited records required to maintain and secure the service.

JobAgent is designed not to process passwords, one-time verification codes, payment-card or bank-account fields, government identity-document fields, electronic signatures, consent declarations, or final submission actions.

3. How information is used

We use the information above only to:

  • authenticate the user and provide the associated JobAgent profile;
  • extract structured information from an uploaded resume for the user to review;
  • match saved information to fields on the active recruitment page;
  • fill fields, continue across application pages, and stop when information is missing or final submission is reached;
  • remember user-approved, non-sensitive custom answers for similar fields;
  • recommend relevant jobs when the user requests that feature; and
  • prevent abuse and maintain the reliability and security of the service.

4. AI processing and service providers

JobAgent uses configured OpenCode Go / DeepSeek AI services to provide features requested by the user. For resume extraction, the resume text is sent to the configured AI service so it can be converted into structured fields. For recruitment-form matching, the service may receive the page title, form labels, options, nearby instructions, and the names of available profile fields. It is not sent the actual values of the user's profile fields for this matching step.

Information may also be processed by hosting and infrastructure providers where this is necessary to operate, secure, and deliver JobAgent. We do not authorize these providers to use JobAgent data for their own advertising or unrelated purposes.

5. Browser storage and permissions

The extension stores the configured server address, invitation-code login session, accepted disclosure version, and non-personal run state on the user's device. Resume answers and completed form values are stored on the JobAgent server rather than in Chrome local storage.

Access to recruitment pages is required to read and fill form controls. Access to the JobAgent server is required to authenticate, retrieve the profile and resume selected by the user, request field-matching decisions, and fetch the resume file. JobAgent does not load or execute remote JavaScript or WebAssembly; all executable extension code is included in the published extension package.

6. Retention, access, and deletion

Resume files, structured profile fields, field memory, and account information are retained while the user's JobAgent account is active or as reasonably necessary to provide the service, resolve security issues, and meet legal obligations. Users can review and edit structured information through the JobAgent profile page. To request access, export, correction, or deletion, contact feng65501@gmail.com. We may ask for reasonable verification before acting on a request.

7. Security

Remote data is transmitted over HTTPS. Server-side session tokens are stored as hashes, and access controls and rate limiting are used to reduce unauthorized access. No online service can guarantee absolute security; users should review completed applications and avoid entering sensitive information into fields that JobAgent intentionally leaves for manual handling.

CHROME WEB STORE LIMITED USE

8. Our data-use commitments

JobAgent's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. In particular:

  • We do not sell or transfer user data to third parties outside the use cases permitted by the Chrome Web Store User Data Policy.
  • We do not use or transfer user data for purposes unrelated to JobAgent's single purpose.
  • We do not use or transfer user data to determine creditworthiness or for lending purposes.

We do not use JobAgent data for personalized, retargeted, or interest-based advertising. Human access is limited to cases permitted by the Chrome Web Store User Data Policy, such as user-authorized support, security investigation, legal compliance, or appropriately aggregated and anonymized internal operations.

9. Changes and contact

We may update this policy when JobAgent's features or data practices change. Material changes will be reflected on this page and, where necessary, disclosed in the extension before additional information is collected. Questions and privacy requests can be sent to feng65501@gmail.com.
